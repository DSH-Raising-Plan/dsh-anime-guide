# dsh-anime-guide

DeepSeek Harness anime plugin: seasonal charts + multi-source rankings, search/recommend, and **domestic vs international contrast**.

> Chinese docs (canonical): [README.md](./README.md)

**Sources:** [yuc.wiki](https://yuc.wiki) · [fankuhub.com/ratings](https://fankuhub.com/ratings) · [bgm.tv rank](https://bgm.tv/anime/browser?sort=rank) · [MAL Top Anime](https://myanimelist.net/topanime.php)

**Tools:** `anime_season` · `anime_ratings` · `anime_search` · `anime_recommend` · `anime_contrast`

## Install

```bash
dsh plugin --profile web add github:DSH-Raising-Plan/dsh-anime-guide#plugin/dsh
```
